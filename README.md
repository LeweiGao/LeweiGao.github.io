# Lewei Gao Portfolio

Static GitHub Pages portfolio.

## Current design

The homepage keeps the warm, minimal hero from the first redesign and uses a dark two-column Selected Work gallery inspired by transit wayfinding. Project tags are the main colour accents. The header is intentionally limited to Email and LinkedIn.

The Ontario Line page uses the same typography and warm background. Section titles use a single vertical route-style marker; the rest of the page is intentionally text- and map-led with minimal decorative UI.

## Main files

- `index.html` — homepage
- `ontario-line.html` — Ontario Line project
- `subway-map-shijiazhuang.html` — Shijiazhuang map project
- `spatial-analysis-of-crimes-toronto.html` — Toronto crime project placeholder
- `assets/css/styles.css` — shared site styles
